# iPhone AI Web App

This version does not require a Mac or Xcode.

## What works
- Mobile AI chat interface
- File picker from iPhone Files
- SHA-256 hashing
- Text preview
- Base64 encode/decode
- URL decode
- Hex decode
- Opens Apple Shortcuts
- Can be added to the iPhone Home Screen

## Important
A real AI model needs a backend URL. Do not put a private API key directly into a public webpage.

## How to use on iPhone
The files must be hosted on a web server (HTTPS is recommended).
Open the site in Safari, tap Share, then Add to Home Screen.

## iOS limitations
A normal web app cannot freely control other apps, tap arbitrary locations, inspect private app data, or automate games.
